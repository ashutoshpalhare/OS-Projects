# Round Robin Scheduling — सोप्या मराठीत मार्गदर्शक

> हा Guide अगदी सुरुवातीपासून शिकणाऱ्या विद्यार्थ्यांसाठी आहे. इंग्रजी Technical Words मुद्दाम तसेच ठेवले आहेत.

## 1. हा Project काय शिकवतो?
Round Robin मध्ये प्रत्येक Process ला CPU वापरण्यासाठी ठरावीक छोटा वेळ मिळतो. वेळ संपल्यावर काम पूर्ण नसेल, तर ते रांगेच्या शेवटी जाते.

## 2. सोप्या शब्दांत महत्त्वाच्या गोष्टी
या ठरावीक वेळेला Time Quantum म्हणतात. हे सर्वांना संधी देणाऱ्या वर्गातील बोलण्याच्या फेरीसारखे आहे.

## 3. Simulator कसा वापरायचा?
AT, BT आणि Time Quantum भरा. Simulation चालवा आणि Gantt Chart मध्ये Process पुन्हा पुन्हा येतो का पाहा.

## 4. छोटं उदाहरण
P1 ला 5 आणि P2 ला 3 वेळ हवा, Quantum=2 असेल तर P1 दोन वेळ काम करेल, मग P2 ला संधी मिळेल.

## 5. लक्षात ठेवण्याची सूत्रे
TAT = CT−AT; WT = TAT−BT.

## 6. या पद्धतीची मर्यादा
Quantum फार मोठा असेल तर FCFS सारखे वाटते; फार लहान असेल तर वारंवार बदलण्याचा खर्च वाढतो.

## 7. स्वतःला विचारून पाहा
- हा Algorithm कोणता Process आधी निवडतो?
- Input बदलल्यावर परिणाम का बदलतो?
- Gantt Chart मध्ये कोणता Process किती वेळ चालला हे कसे समजते?

## 8. महत्त्वाची नोंद
हा शैक्षणिक Simulator आहे. तो Operating System च्या कल्पना समजावण्यासाठी बनवला आहे; खऱ्या Computer मधील OS चे सर्व तपशील तो दाखवत नाही.

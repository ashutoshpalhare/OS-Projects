# SRTF CPU Scheduling — सोप्या मराठीत मार्गदर्शक

> हा Guide अगदी सुरुवातीपासून शिकणाऱ्या विद्यार्थ्यांसाठी आहे. इंग्रजी Technical Words मुद्दाम तसेच ठेवले आहेत.

## 1. हा Project काय शिकवतो?
SRTF म्हणजे Shortest Remaining Time First. CPU सध्या चालू असलेल्या कामापेक्षा कमी उरलेला वेळ असलेला नवीन Process आला, तर CPU काम बदलू शकतो.

## 2. सोप्या शब्दांत महत्त्वाच्या गोष्टी
Remaining Time म्हणजे Process पूर्ण होण्यासाठी अजून किती CPU वेळ हवा आहे. काम मध्ये थांबवून दुसरे काम चालवणे म्हणजे Preemption.

## 3. Simulator कसा वापरायचा?
AT आणि BT भरा, Run दाबा आणि Gantt Chart मधील बदल पाहा. लवकर आलेल्या Process च्या मध्ये दुसरा Process येतो तेव्हा काय होते ते लक्षात घ्या.

## 4. छोटं उदाहरण
P1 ला 8 वेळ लागतो आणि वेळ 2 ला P2 येतो ज्याला 3 वेळ लागतो. P1 ने 2 वेळ काम केलेले असते; उरलेले 6. P2 चे 3 कमी असल्याने तो आधी चालू शकतो.

## 5. लक्षात ठेवण्याची सूत्रे
TAT = CT−AT; WT = TAT−BT.

## 6. या पद्धतीची मर्यादा
वारंवार छोटे Process आल्यास मोठा Process खूप वेळ थांबू शकतो; याला Starvation होऊ शकते.

## 7. स्वतःला विचारून पाहा
- हा Algorithm कोणता Process आधी निवडतो?
- Input बदलल्यावर परिणाम का बदलतो?
- Gantt Chart मध्ये कोणता Process किती वेळ चालला हे कसे समजते?

## 8. महत्त्वाची नोंद
हा शैक्षणिक Simulator आहे. तो Operating System च्या कल्पना समजावण्यासाठी बनवला आहे; खऱ्या Computer मधील OS चे सर्व तपशील तो दाखवत नाही.

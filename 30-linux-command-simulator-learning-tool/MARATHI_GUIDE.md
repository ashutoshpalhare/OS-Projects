# Linux Command Simulator — सोप्या मराठीत मार्गदर्शक

> कठीण शब्द कमी ठेवून, रोजच्या उदाहरणांनी संकल्पना समजावण्याचा प्रयत्न.

## 1. हा Project काय करतो?
Linux मध्ये Command Line वापरून संगणकाला मजकूर आदेश देता येतात. हा Simulator सुरक्षित, बनावट terminal मध्ये commands चा सराव करू देतो.

## 2. महत्त्वाचे शब्द
pwd = सध्याचा folder; ls = files/folders ची यादी; cd = folder बदलणे; mkdir = folder तयार करणे; touch = file तयार करणे; cat = file वाचणे; help = मदत.

## 3. वापरण्याची पद्धत
Command box मध्ये help लिहून Enter दाबा. नंतर pwd, ls, mkdir practice, cd practice, touch hello.txt, ls हे करून पहा.

## 4. छोटं उदाहरण
mkdir practice ने folder तयार होतो; cd practice ने त्यात जाता येते; touch hello.txt ने simulated file तयार होते.

## 5. मुख्य नियम
Command चा परिणाम command, current directory आणि दिलेल्या argument वर अवलंबून असतो.

## 6. मर्यादा
हा simulated terminal आहे. यात दिलेल्या commands तुमच्या खऱ्या Computer मधील files बदलत नाहीत.

## 7. स्वतः करून पाहा
- Example चालवून पहा.
- एक input बदला आणि परिणामात काय बदलले ते लिहा.
- हा विषय Operating System मध्ये का महत्त्वाचा आहे ते एका वाक्यात सांगा.

## 8. लक्षात ठेवा
हा विद्यार्थ्यांसाठी तयार केलेला शैक्षणिक Simulator आहे. प्रत्यक्ष Operating System मध्ये अधिक नियम आणि परिस्थिती असू शकतात.

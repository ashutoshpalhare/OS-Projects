# Linux Command Simulator & Learning Tool

## Overview
Safe mock terminal for practicing navigation, directories, and simulated file commands in the browser.

## Learning objectives
- Understand the relevant Operating Systems concept.
- Observe state changes through an interactive interface.
- Interpret the operation log and explain the behavior.

## Technologies
HTML5, CSS3, Vanilla JavaScript.

## Run
Open `index.html` in a modern browser and use the controls.

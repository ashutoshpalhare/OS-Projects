How Priority Scheduling Works

  1. Find all processes that have arrived.
  2. Select the available process with the highest priority.
  3. In this simulator, the smaller priority number means higher priority.
  4. Run the selected process completely because this is Non-Preemptive Priority Scheduling.
  5. Repeat until every process completes.

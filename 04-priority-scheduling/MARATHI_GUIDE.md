# Priority Scheduling — सोप्या मराठीत मार्गदर्शक

> हा Guide अगदी सुरुवातीपासून शिकणाऱ्या विद्यार्थ्यांसाठी आहे. इंग्रजी Technical Words मुद्दाम तसेच ठेवले आहेत.

## 1. हा Project काय शिकवतो?
Priority Scheduling मध्ये प्रत्येक Process ला महत्त्वाचा क्रमांक दिला जातो. जास्त प्राधान्य असलेला Process आधी CPU मिळवतो.

## 2. सोप्या शब्दांत महत्त्वाच्या गोष्टी
या Simulator मध्ये Priority ची संख्या कमी असेल तर प्राधान्य जास्त असू शकते—स्क्रीनवरील सूचना तपासा. समान Priority असल्यास Arrival Time वापरला जाऊ शकतो.

## 3. Simulator कसा वापरायचा?
प्रत्येक Process साठी AT, BT आणि Priority भरा. Run करा आणि निवडलेला क्रम तपासा.

## 4. छोटं उदाहरण
P1 Priority=3, P2 Priority=1, P3 Priority=2 आणि सर्व एकाच वेळी आले, तर लहान क्रमांकाला जास्त प्राधान्य असल्यास P2 आधी.

## 5. लक्षात ठेवण्याची सूत्रे
WT = TAT−BT; TAT = CT−AT.

## 6. या पद्धतीची मर्यादा
कमी प्राधान्याचे काम सतत थांबू शकते. Aging वापरून वाट पाहणाऱ्या Process चे प्राधान्य वाढवता येते.

## 7. स्वतःला विचारून पाहा

## 8. महत्त्वाची नोंद
हा शैक्षणिक Simulator आहे. तो Operating System च्या कल्पना समजावण्यासाठी बनवला आहे; खऱ्या Computer मधील OS चे सर्व तपशील तो दाखवत नाही.

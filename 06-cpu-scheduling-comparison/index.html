Algorithms Compared

  1. FCFS: Executes processes in Arrival Time order.
  2. SJF: Selects the arrived process with the smallest Burst Time.
  3. Priority: Selects the arrived process with the highest priority (smallest priority number).
  4. Round Robin: Uses a fixed Time Quantum and cyclic Ready Queue.

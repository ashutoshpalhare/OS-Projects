# Round Robin CPU Scheduling — सोप्या मराठीत मार्गदर्शक

> हा Guide अगदी सुरुवातीपासून शिकणाऱ्या विद्यार्थ्यांसाठी आहे.

## 1. हा Project काय शिकवतो?
Round Robin मध्ये प्रत्येक Process ला CPU वापरण्यासाठी ठरावीक छोटा वेळ मिळतो. वेळ संपल्यावर काम पूर्ण नसेल, तर ते रांगेच्या शेवटी जाते. हे वर्गातील प्रत्येक विद्यार्थ्याला बोलण्याची संधी मिळण्यासारखे आहे.

## 2. महत्त्वाचे शब्द
- **Process:** चालू असलेले काम.
- **Burst Time (BT):** CPU ला काम पूर्ण करण्यासाठी लागणारा एकूण वेळ.
- **Time Quantum:** एका फेरीत Process ला मिळणारा वेळ.
- **Ready Queue:** CPU ची वाट पाहणाऱ्या Processes ची रांग.

## 3. Simulator कसा वापरायचा?
1. Processes ची Arrival Time आणि Burst Time भरा.
2. Time Quantum सेट करा.
3. Simulation चालवा.
4. Gantt Chart मध्ये कोणाला किती वेळ मिळाला ते पहा.

## 4. छोटं उदाहरण
P1 ला 5 वेळ आणि P2 ला 3 वेळ हवा आहे. Time Quantum = 2 असेल, तर P1 आधी 2 वेळ काम करेल, मग P2 ला संधी मिळेल. P1 चे काम बाकी असल्यामुळे तो पुन्हा रांगेत येईल.

## 5. लक्षात ठेवण्याची गोष्ट
Time Quantum खूप मोठा असेल तर पद्धत FCFS सारखी वाटू शकते. खूप लहान असेल तर Process बदलण्याची वारंवारता वाढते.

## 6. स्वतःला विचारून पाहा

- कोणत्या Process ला किती वेळा CPU मिळाला?

## 7. महत्त्वाची नोंद
हा शैक्षणिक Simulator आहे. तो Operating System ची संकल्पना समजावतो; प्रत्यक्ष OS मधील सर्व तपशील दाखवत नाही.

# Resource Allocation Graph — सोप्या मराठीत मार्गदर्शक

> हा Guide शालेय विद्यार्थ्यांनाही समजेल अशा सोप्या उदाहरणांसह लिहिला आहे.

## 1. मुख्य कल्पना
Resource Allocation Graph हा चित्ररूप नकाशा आहे. त्यात Processes आणि Resources नोड्स असतात आणि बाण कोण काय मागतो किंवा कोणाकडे आहे हे दाखवतात.

## 2. महत्त्वाचे शब्द
Process → Resource म्हणजे Process ला Resource हवा आहे; Resource → Process म्हणजे Resource त्या Process ला दिला आहे.

## 3. Simulator कसा वापरायचा?
Nodes/edges जोडा किंवा उदाहरण load करा. बाणांची दिशा पाहा आणि चक्र (Cycle) आहे का ते तपासा.

## 4. छोटं उदाहरण
P1 → R1, R1 → P2, P2 → R2, R2 → P1 असे बाण असल्यास cycle तयार होते.

## 5. लक्षात ठेवण्याचा नियम
Single-instance Resource model मध्ये cycle deadlock दर्शवू शकतो; अनेक instances असतील तर cycle एकटाच पुरेसा पुरावा नसतो.

## 6. काळजी / मर्यादा
चित्रातील प्रत्येक बाणाचा अर्थ नीट समजून घ्या; फक्त रेषा छेदतात म्हणून cycle होत नाही.

## 7. स्वतःला विचारा
- कोणाकडे कोणते Resources आहेत?
- पुढे कोणती कृती होऊ शकते?
- निकाल सुरक्षित, अडकलेला किंवा अवैध का आहे?

## 8. लक्षात ठेवा
हा शैक्षणिक model आहे. खऱ्या Operating System मधील परिस्थिती यापेक्षा मोठी असू शकते.

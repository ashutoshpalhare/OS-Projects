# Interactive Gantt Chart Visualizer — सोप्या मराठीत मार्गदर्शक

> हा Guide अगदी सुरुवातीपासून शिकणाऱ्या विद्यार्थ्यांसाठी आहे. Technical Words सोपे करून समजावले आहेत.

## 1. हा Project काय शिकवतो?
Gantt Chart म्हणजे वेळेनुसार कोणता Process CPU वापरत होता हे दाखवणारी पट्टी. रेल्वे वेळापत्रकासारखे समजा—प्रत्येक पट्टा कोणाला आणि किती वेळ मिळाला ते दाखवतो.

## 2. महत्त्वाचे शब्द
पट्टीतील Process चे नाव काम करणारा Process दाखवते; पट्टीची लांबी त्याला मिळालेला वेळ दाखवते. सुरुवातीचा आणि शेवटचा अंक वेळ दाखवतो.

## 3. Simulator वापरण्याची पद्धत
दिलेल्या controls मधून Process किंवा वेळ बदला आणि Chart तयार करा. प्रत्येक पट्टीची सुरुवात, शेवट आणि लांबी पाहा.

## 4. छोटं उदाहरण
P1 वेळ 0 ते 3 आणि P2 वेळ 3 ते 7 चालला, तर P1 ची पट्टी 3 units आणि P2 ची 4 units लांबीची असेल.

## 5. लक्षात ठेवण्याची गोष्ट
Duration = End Time−Start Time.

## 6. मर्यादा
Gantt Chart हा परिणाम दाखवतो; तो स्वतःहून योग्य scheduling algorithm ठरवत नाही.

## 7. स्वतःला विचारून पाहा
- Input बदलल्यावर काय बदलले?
- स्क्रीनवरील क्रम/स्थिती कशी समजते?
- ही संकल्पना खऱ्या Operating System मध्ये कशासाठी उपयोगी आहे?

## 8. महत्त्वाची नोंद
हा शैक्षणिक Simulator आहे. तो संकल्पना समजावतो; खऱ्या Operating System मधील प्रत्येक तपशील दाखवत नाही.

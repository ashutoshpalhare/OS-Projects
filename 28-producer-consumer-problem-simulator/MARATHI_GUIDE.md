# Producer–Consumer Problem — सोप्या मराठीत मार्गदर्शक

> कठीण शब्द कमी ठेवून, रोजच्या उदाहरणांनी संकल्पना समजावण्याचा प्रयत्न.

## 1. हा Project काय करतो?
Producer नवीन वस्तू तयार करून shared buffer मध्ये ठेवतो. Consumer त्या buffer मधून वस्तू घेतो. Buffer भरला किंवा रिकामा झाला तर योग्य थांबणे आवश्यक असते.

## 2. महत्त्वाचे शब्द
Buffer = तात्पुरती ठेवण्याची जागा; Producer = वस्तू तयार करणारा; Consumer = वस्तू वापरणारा; Synchronization = दोघांनी सुरक्षितपणे काम करणे.

## 3. वापरण्याची पद्धत
Buffer capacity ठेवा, Producer/Consumer actions चालवा आणि किती वस्तू आत आहेत ते पहा. Buffer full/empty झाल्यावर काय होते ते समजा.

## 4. छोटं उदाहरण
Capacity 3 असताना Producer ने 3 वस्तू ठेवल्या तर buffer full होतो. अजून वस्तू ठेवण्याआधी जागा मोकळी व्हावी लागते.

## 5. मुख्य नियम
Buffer मध्ये वस्तूंची संख्या 0 पेक्षा कमी किंवा capacity पेक्षा जास्त नसावी.

## 6. मर्यादा
Synchronization नसेल तर data हरवू शकतो किंवा चुकीचा क्रम होऊ शकतो.

## 7. स्वतः करून पाहा
- Example चालवून पहा.
- एक input बदला आणि परिणामात काय बदलले ते लिहा.
- हा विषय Operating System मध्ये का महत्त्वाचा आहे ते एका वाक्यात सांगा.

## 8. लक्षात ठेवा
हा विद्यार्थ्यांसाठी तयार केलेला शैक्षणिक Simulator आहे. प्रत्यक्ष Operating System मध्ये अधिक नियम आणि परिस्थिती असू शकतात.

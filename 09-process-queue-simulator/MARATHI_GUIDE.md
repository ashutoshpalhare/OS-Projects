# Process Queue Simulator — सोप्या मराठीत मार्गदर्शक

> हा Guide अगदी सुरुवातीपासून शिकणाऱ्या विद्यार्थ्यांसाठी आहे. Technical Words सोपे करून समजावले आहेत.

## 1. हा Project काय शिकवतो?
Queue म्हणजे रांग. Operating System मध्ये तयार असलेले Processes CPU, disk किंवा इतर साधनांची वाट पाहण्यासाठी रांगेत राहू शकतात.

## 2. महत्त्वाचे शब्द
Enqueue = रांगेत घालणे; Dequeue = रांगेतून काढणे; Front = पुढचा Process; Rear = शेवटचा Process.

## 3. Simulator वापरण्याची पद्धत
Add/Enqueue वापरून Process घाला. Remove/Dequeue करून पुढचा काढा. रांगेतील क्रम पहा.

## 4. छोटं उदाहरण
रांगेत P1, P2, P3 या क्रमाने आले, तर साध्या FIFO Queue मध्ये P1 आधी बाहेर पडेल.

## 5. लक्षात ठेवण्याची गोष्ट
FIFO Queue मध्ये आधी आलेला घटक आधी बाहेर पडतो.

## 6. मर्यादा
सर्व Queue एकसारख्या नसतात; Priority Queue मध्ये महत्त्वानुसार क्रम बदलू शकतो.

## 7. स्वतःला विचारून पाहा
- Input बदलल्यावर काय बदलले?
- स्क्रीनवरील क्रम/स्थिती कशी समजते?
- ही संकल्पना खऱ्या Operating System मध्ये कशासाठी उपयोगी आहे?

## 8. महत्त्वाची नोंद
हा शैक्षणिक Simulator आहे. तो संकल्पना समजावतो; खऱ्या Operating System मधील प्रत्येक तपशील दाखवत नाही.

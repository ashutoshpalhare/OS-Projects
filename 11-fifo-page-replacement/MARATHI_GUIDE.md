# FIFO Page Replacement — सोप्या मराठीत मार्गदर्शक

> 15 वर्षांच्या विद्यार्थ्यालाही समजेल अशा भाषेत.

## 1. हा Project काय शिकवतो?
Computer ची RAM मर्यादित असते. नवीन Page आणण्यासाठी जागा नसेल, तर FIFO पद्धत सर्वात आधी RAM मध्ये आलेला Page बाहेर काढते.

## 2. सोपे शब्द
Page = Program चा memory मधील छोटा भाग; Frame = RAM मधील जागा; Page Fault = लागलेला Page RAM मध्ये नसणे.

## 3. वापरण्याची पद्धत
Reference String मध्ये Pages चा क्रम द्या, Frames ची संख्या निवडा आणि simulation चालवा. प्रत्येक टप्प्यावर कोणता Page बाहेर जातो ते पाहा.

## 4. उदाहरण
Frames=3 आणि क्रम 1,2,3,4 असेल, तर 1,2,3 भरल्यानंतर 4 साठी सर्वात आधी आलेला Page 1 बाहेर जाऊ शकतो.

## 5. लक्षात ठेवण्यासारखे
Page Fault Count = RAM मध्ये नसलेल्या Page मुळे झालेल्या Fault ची संख्या.

## 6. मर्यादा
FIFO सोपा आहे, पण Page किती वेळा वापरला गेला हे पाहत नाही.

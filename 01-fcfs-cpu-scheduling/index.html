What is FCFS?

First Come First Serve is a non-preemptive CPU scheduling algorithm. The process that arrives first gets the CPU first and runs until completion.

Key Formulas

Turnaround Time = Completion Time − Arrival Time

Waiting Time = Turnaround Time − Burst Time

Response Time = Start Time − Arrival Time

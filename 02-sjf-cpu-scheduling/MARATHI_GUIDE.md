# SJF CPU Scheduling — सोप्या मराठीत मार्गदर्शक

> हा Guide अगदी सुरुवातीपासून शिकणाऱ्या विद्यार्थ्यांसाठी आहे. इंग्रजी Technical Words मुद्दाम तसेच ठेवले आहेत.

## 1. हा Project काय शिकवतो?
SJF म्हणजे Shortest Job First. CPU रिकामा झाल्यावर तयार असलेल्या Processes पैकी सर्वात कमी वेळ घेणारा Process आधी निवडला जातो.

## 2. सोप्या शब्दांत महत्त्वाच्या गोष्टी
Burst Time म्हणजे काम पूर्ण करण्यासाठी लागणारा CPU वेळ. या साध्या SJF मध्ये निवडलेला Process पूर्ण होईपर्यंत चालतो; याला Non-preemptive म्हणतात.

## 3. Simulator कसा वापरायचा?
Processes ची Arrival Time आणि Burst Time भरा, simulation चालवा आणि Gantt Chart मधील क्रम व averages पाहा.

## 4. छोटं उदाहरण
P1 BT=6, P2 BT=2, P3 BT=4 आणि तिघेही वेळ 0 ला आले, तर क्रम P2, P3, P1 होईल.

## 5. लक्षात ठेवण्याची सूत्रे
WT = Start Time−AT; TAT = CT−AT.

## 6. या पद्धतीची मर्यादा
लहान कामांना प्राधान्य मिळते; पण मोठे काम वारंवार मागे पडू शकते.

## 7. स्वतःला विचारून पाहा
- हा Algorithm कोणता Process आधी निवडतो?
- Input बदलल्यावर परिणाम का बदलतो?
- Gantt Chart मध्ये कोणता Process किती वेळ चालला हे कसे समजते?

## 8. महत्त्वाची नोंद
हा शैक्षणिक Simulator आहे. तो Operating System च्या कल्पना समजावण्यासाठी बनवला आहे; खऱ्या Computer मधील OS चे सर्व तपशील तो दाखवत नाही.

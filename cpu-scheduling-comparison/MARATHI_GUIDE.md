# CPU Scheduling Algorithm Comparison — सोप्या मराठीत मार्गदर्शक

> हा Guide अगदी सुरुवातीपासून शिकणाऱ्या विद्यार्थ्यांसाठी आहे. Technical Words सोपे करून समजावले आहेत.

## 1. हा Project काय शिकवतो?
हा Project वेगवेगळे CPU Scheduling Algorithms एकाच input वर तुलना करायला मदत करतो. जसे एकाच प्रश्नासाठी वेगवेगळ्या पद्धती वापरून वेळेची तुलना करणे.

## 2. महत्त्वाचे शब्द
FCFS आधी आलेल्याला निवडतो; SJF कमी Burst Time निवडतो; SRTF कमी Remaining Time निवडतो; Priority महत्त्वानुसार निवडतो; Round Robin प्रत्येकाला वेळ देतो.

## 3. Simulator वापरण्याची पद्धत
एकसारखे Processes भरा, उपलब्ध Algorithms निवडा आणि प्रत्येकाचा Waiting Time, Turnaround Time व Gantt Chart तुलना करा.

## 4. छोटं उदाहरण
चार Processes एकाच वेळी आले आणि Burst Time वेगवेगळे आहेत. SJF मध्ये लहान काम आधी होऊ शकते, तर FCFS मध्ये input क्रम महत्त्वाचा ठरतो.

## 5. लक्षात ठेवण्याची गोष्ट
Average WT = सर्व WT ची बेरीज ÷ Processes ची संख्या. Average TAT साठीही हीच पद्धत.

## 6. मर्यादा
एकच Algorithm प्रत्येक परिस्थितीत सर्वोत्तम असेलच असे नाही; उद्दिष्ट आणि input यानुसार परिणाम बदलतो.

## 7. स्वतःला विचारून पाहा
- Input बदलल्यावर काय बदलले?
- स्क्रीनवरील क्रम/स्थिती कशी समजते?
- ही संकल्पना खऱ्या Operating System मध्ये कशासाठी उपयोगी आहे?

## 8. महत्त्वाची नोंद
हा शैक्षणिक Simulator आहे. तो संकल्पना समजावतो; खऱ्या Operating System मधील प्रत्येक तपशील दाखवत नाही.

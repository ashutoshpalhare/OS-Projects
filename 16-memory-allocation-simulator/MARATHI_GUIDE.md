# Memory Allocation Simulator — सोप्या मराठीत मार्गदर्शक

> हा Guide शालेय विद्यार्थ्यांनाही समजेल अशा सोप्या उदाहरणांसह लिहिला आहे.

## 1. मुख्य कल्पना
Program चालवण्यासाठी Operating System ला RAM मध्ये जागा द्यावी लागते. Memory Allocation म्हणजे प्रत्येक Program ला योग्य जागा वाटून देणे.

## 2. महत्त्वाचे शब्द
First Fit = पहिली पुरेशी जागा; Best Fit = गरजेच्या जवळची लहान पुरेशी जागा; Worst Fit = सर्वात मोठी उपलब्ध जागा.

## 3. Simulator कसा वापरायचा?
Memory Blocks आणि Process ची गरज भरा. Allocation पद्धत निवडा आणि कोणत्या Process ला कोणता Block मिळाला ते पहा.

## 4. छोटं उदाहरण
Free Blocks 100, 500, 200 आणि Process ची गरज 180 असेल, तर First Fit मध्ये 500 हा पहिला पुरेसा Block निवडला जाऊ शकतो.

## 5. लक्षात ठेवण्याचा नियम
Internal Fragmentation = दिलेल्या Block मध्ये न वापरलेली जागा; External Fragmentation = एकूण जागा असूनही ती वेगवेगळ्या छोट्या तुकड्यांत असणे.

## 6. काळजी / मर्यादा
एकाच पद्धतीचा निकाल प्रत्येक memory layout मध्ये चांगला असेलच असे नाही.

## 7. स्वतःला विचारा
- कोणाकडे कोणते Resources आहेत?
- पुढे कोणती कृती होऊ शकते?
- निकाल सुरक्षित, अडकलेला किंवा अवैध का आहे?

## 8. लक्षात ठेवा
हा शैक्षणिक model आहे. खऱ्या Operating System मधील परिस्थिती यापेक्षा मोठी असू शकते.

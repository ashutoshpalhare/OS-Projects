How Segmentation Works

  1. A logical address contains a segment number and an offset.
  2. The segment number selects an entry from the segment table.
  3. The offset must be smaller than the segment's limit.
  4. If valid, physical address = base + offset.
  5. If offset ≥ limit, a segmentation fault occurs.

Key Formulas

Logical Address = (Segment Number, Offset)
0 ≤ Offset < Limit
Physical Address = Base + Offset

Segmentation provides a logical view of memory based on program segments such as Code, Data, Stack and Heap.

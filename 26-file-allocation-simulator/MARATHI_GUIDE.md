# File Allocation Simulator — सोप्या मराठीत मार्गदर्शक

> कठीण शब्द कमी ठेवून, रोजच्या उदाहरणांनी संकल्पना समजावण्याचा प्रयत्न.

## 1. हा Project काय करतो?
Operating System ला Files disk वर कुठे ठेवायच्या आणि त्यांचे blocks कसे जोडायचे हे ठरवावे लागते. File Allocation पद्धत फाइलचा डेटा शोधायला मदत करते.

## 2. महत्त्वाचे शब्द
Contiguous Allocation = सलग blocks; Linked Allocation = प्रत्येक block पुढच्या block चा पत्ता ठेवतो; Indexed Allocation = वेगळ्या index मध्ये blocks ची यादी.

## 3. वापरण्याची पद्धत
File चे नाव/आकार द्या किंवा पद्धत निवडा. Disk blocks मध्ये फाइल कशी ठेवली जाते ते पाहा.

## 4. छोटं उदाहरण
फाइलला 3 blocks लागतात. Contiguous पद्धतीत 10,11,12 असे सलग blocks मिळू शकतात; Linked पद्धतीत 4,9,15 असे वेगवेगळे blocks जोडले जाऊ शकतात.

## 5. मुख्य नियम
फाइलसाठी लागणारे blocks आणि त्यांचे addresses पद्धतीनुसार बदलतात.

## 6. मर्यादा
सलग जागा नसेल तर Contiguous Allocation करणे कठीण होऊ शकते; Linked मध्ये थेट मधला block शोधणे अवघड असू शकते.

## 7. स्वतः करून पाहा
- Example चालवून पहा.
- एक input बदला आणि परिणामात काय बदलले ते लिहा.
- हा विषय Operating System मध्ये का महत्त्वाचा आहे ते एका वाक्यात सांगा.

## 8. लक्षात ठेवा
हा विद्यार्थ्यांसाठी तयार केलेला शैक्षणिक Simulator आहे. प्रत्यक्ष Operating System मध्ये अधिक नियम आणि परिस्थिती असू शकतात.

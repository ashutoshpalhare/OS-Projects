# Project 16 – Memory Allocation Simulator

A browser-based Operating Systems project demonstrating First Fit, Best Fit and Worst Fit memory allocation strategies.

## Features
- Custom memory block sizes
- Custom process sizes
- First Fit allocation
- Best Fit allocation
- Worst Fit allocation
- Allocation success comparison
- Remaining free memory
- Process-by-process allocation table
- Load Example and Reset
- Responsive UI
- Dark mode
- HTML5, CSS3 and JavaScript only

## Algorithms
### First Fit
Scans memory blocks from the beginning and allocates a process to the first block large enough.

### Best Fit
Searches all available blocks and chooses the smallest block that is large enough for the process.

### Worst Fit
Searches all available blocks and chooses the largest block that can accommodate the process.

## Example
Memory Blocks: 100, 500, 200, 300, 600  
Processes: 212, 417, 112, 426

## Educational Objective
Students can understand contiguous memory allocation and compare how First Fit, Best Fit and Worst Fit produce different allocation patterns and fragmentation.

## How to Run
Open index.html in a modern web browser. No installation or backend is required.

Key Concepts

  • Virtual memory gives each process a virtual address space.
  • Memory is divided into fixed-size pages and physical memory into frames.
  • The page table maps virtual pages to physical frames.
  • A page not present in memory causes a page fault.

Translation Formula

For a virtual address VA and page size S:

Page Number = floor(VA / S)
Offset = VA mod S
Physical Address = Frame × S + Offset

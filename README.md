# Operating Systems Projects — Individual Delivery Collection

This repository contains **30 separate browser-based Operating Systems projects** for student delivery. Each project lives in its own unnumbered folder and can be copied or downloaded independently.

## Folder contents
Every project folder includes:
- `index.html` — project interface
- `css/style.css` — project-specific styles
- `js/app.js` — simulation logic
- `README.md` — project notes
- `MARATHI_GUIDE.md` — a beginner-friendly explanation in simple Marathi
- `assets/site.css` and `assets/site.js` — the shared visual enhancements copied locally so the folder remains self-contained

## How to run a project
1. Download only the required project folder.
2. Keep its internal folder structure unchanged.
3. Open that folder's `index.html` in a modern browser.
4. For CDN libraries, icons, and web fonts, an internet connection may be needed.

## Important
These are educational simulations. They demonstrate selected Operating Systems concepts and do not reproduce every detail of a real operating system.

## Technology
HTML5 · CSS3 · Vanilla JavaScript · Bootstrap CDN · Bootstrap Icons · Lucide Icons where used.

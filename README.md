# OS Interactive Lab — 30 Operating Systems Projects

A collection of 30 browser-based Operating Systems learning projects built with **HTML, CSS, and Vanilla JavaScript**.

## Start here
Open [index.html](./index.html) to browse all projects. Choose a project card to launch its simulator.

## What is included?
- CPU scheduling and Gantt chart visualizations
- Process states and queues
- Page replacement and virtual memory
- Memory allocation and segmentation
- Deadlock detection, prevention, and avoidance
- Disk scheduling
- File allocation
- Producer–Consumer and Dining Philosophers synchronization examples
- Linux command practice in a simulated terminal

## Project folder structure
Each numbered project folder should contain:
- `index.html` — the web interface
- `css/style.css` — project-specific styles
- `js/app.js` — simulation logic
- `README.md` — project and implementation notes
- `MARATHI_GUIDE.md` — a simple Marathi explanation for beginners

Shared UI files are stored in `assets/site.css` and `assets/site.js`.

## Run locally
1. Download or clone this repository.
2. Open the root `index.html` in a modern browser.
3. Open a project from the dashboard.

Most projects run directly in a browser. An internet connection is needed for CDN libraries, web fonts, and the dashboard's remote image.

## Important learning note
These are educational simulations, not replacements for a real Operating System. Check each project's guide and README to understand assumptions and limitations. Try changing the inputs and explaining why the results change.

## Technology
HTML5 · CSS3 · Vanilla JavaScript · Bootstrap CDN · Bootstrap Icons · Lucide Icons where used.

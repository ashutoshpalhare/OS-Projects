# Deadlock Detection Simulator — सोप्या मराठीत मार्गदर्शक

> हा Guide शालेय विद्यार्थ्यांनाही समजेल अशा सोप्या उदाहरणांसह लिहिला आहे.

## 1. मुख्य कल्पना
Deadlock म्हणजे दोन किंवा अधिक Processes एकमेकांकडील Resources सुटण्याची वाट पाहत अडकतात आणि पुढे जाऊ शकत नाहीत.

## 2. महत्त्वाचे शब्द
Process ला Resource हवा असतो. काही Resources आधीच दुसऱ्याकडे असतात. Detection algorithm उपलब्ध Resources वापरून कोण पूर्ण होऊ शकते हे तपासतो.

## 3. Simulator कसा वापरायचा?
Resource allocation किंवा request स्थिती द्या. Detect/Analyze दाबा आणि कोणते Processes पूर्ण होऊ शकतात किंवा अडकू शकतात ते पाहा.

## 4. छोटं उदाहरण
P1 कडे Printer असून Scanner हवा; P2 कडे Scanner असून Printer हवा. दोघेही दुसऱ्याची वाट पाहत असतील तर deadlock होऊ शकतो.

## 5. लक्षात ठेवण्याचा नियम
सुरक्षित पूर्णता क्रम सापडत नसणे हे दिलेल्या स्थितीत अडकण्याचे चिन्ह असू शकते; नेमका निष्कर्ष simulator च्या model वर अवलंबून असतो.

## 6. काळजी / मर्यादा
Deadlock आणि फक्त Slow Performance या वेगळ्या गोष्टी आहेत.

## 7. स्वतःला विचारा
- कोणाकडे कोणते Resources आहेत?
- पुढे कोणती कृती होऊ शकते?
- निकाल सुरक्षित, अडकलेला किंवा अवैध का आहे?

## 8. लक्षात ठेवा
हा शैक्षणिक model आहे. खऱ्या Operating System मधील परिस्थिती यापेक्षा मोठी असू शकते.

# Process State Transition Simulator — सोप्या मराठीत मार्गदर्शक

> हा Guide अगदी सुरुवातीपासून शिकणाऱ्या विद्यार्थ्यांसाठी आहे. Technical Words सोपे करून समजावले आहेत.

## 1. हा Project काय शिकवतो?
Program चालू असताना त्याची स्थिती बदलते. Process नवीन असतो, CPU ची वाट पाहतो, चालतो, I/O साठी थांबतो आणि शेवटी पूर्ण होतो.

## 2. महत्त्वाचे शब्द
New = नवीन; Ready = CPU ची वाट; Running = CPU वापरत आहे; Waiting/Blocked = एखाद्या गोष्टीची वाट; Terminated = पूर्ण.

## 3. Simulator वापरण्याची पद्धत
Simulator मधील Process निवडा किंवा action बटणे वापरा. प्रत्येक action नंतर state कशी बदलते ते पाहा.

## 4. छोटं उदाहरण
एखादा Process Ready मधून Running होतो. Disk वाचण्याची वाट लागली तर Waiting मध्ये जाऊ शकतो; काम पूर्ण झाल्यावर Terminated होतो.

## 5. लक्षात ठेवण्याची गोष्ट
ही मुख्यतः State Transition ची संकल्पना आहे; प्रत्येक स्थितीतील वेळ OS आणि कामावर अवलंबून असतो.

## 6. मर्यादा
प्रत्येक Process ने नेहमी एकाच क्रमाने सर्व states पार करायलाच हवेत असे नाही.

## 7. स्वतःला विचारून पाहा
- Input बदलल्यावर काय बदलले?
- स्क्रीनवरील क्रम/स्थिती कशी समजते?
- ही संकल्पना खऱ्या Operating System मध्ये कशासाठी उपयोगी आहे?

## 8. महत्त्वाची नोंद
हा शैक्षणिक Simulator आहे. तो संकल्पना समजावतो; खऱ्या Operating System मधील प्रत्येक तपशील दाखवत नाही.

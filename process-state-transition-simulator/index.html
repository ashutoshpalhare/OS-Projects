Valid Transitions

  • New → Ready: Process is admitted to the ready queue.
  • Ready → Running: CPU scheduler dispatches the process.
  • Running → Waiting: Process requests I/O or waits for an event.
  • Waiting → Ready: I/O or required event is completed.
  • Running → Ready: Process is preempted.
  • Running → Terminated: Process finishes execution.

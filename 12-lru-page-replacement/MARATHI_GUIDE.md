# LRU Page Replacement — सोप्या मराठीत मार्गदर्शक

> 15 वर्षांच्या विद्यार्थ्यालाही समजेल अशा भाषेत.

## 1. हा Project काय शिकवतो?
LRU म्हणजे Least Recently Used. RAM मध्ये जागा नसेल तर सर्वात बराच वेळ वापरला न गेलेला Page बाहेर काढतो.

## 2. सोपे शब्द
Recently Used म्हणजे अलीकडे वापरलेला. LRU मागचा वापर पाहतो; पुढे कोणता Page लागेल याचा अंदाज लावत नाही.

## 3. वापरण्याची पद्धत
Reference String आणि Frame संख्या द्या. प्रत्येक Page access नंतर कोणता Page सर्वात जुना वापरलेला आहे ते पहा.

## 4. उदाहरण
Frames मध्ये 1,2,3 आहेत आणि अलीकडे 2 व 3 वापरले गेले; 1 सर्वात आधीपासून न वापरलेला असेल, तर 1 बाहेर जाऊ शकतो.

## 5. लक्षात ठेवण्यासारखे
Page Fault म्हणजे मागितलेला Page Frames मध्ये न सापडणे.

## 6. मर्यादा
LRU ला मागील वापराची माहिती ठेवावी लागते; प्रत्यक्ष OS मध्ये त्याची अंमलबजावणी खर्चिक असू शकते.

## 7. स्वतः तपासा
- Frames ची संख्या बदलल्यावर काय होते?
- कोणता Page बाहेर काढला गेला आणि का?
- दोन Algorithms चा निकाल वेगळा का असू शकतो?

## 8. लक्षात ठेवा
हा प्रात्यक्षिकासाठीचा Simulator आहे. स्क्रीनवरील परिणाम समजून घेणे हा उद्देश आहे.

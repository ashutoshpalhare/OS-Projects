# Optimal Page Replacement — सोप्या मराठीत मार्गदर्शक

> 15 वर्षांच्या विद्यार्थ्यालाही समजेल अशा भाषेत.

## 1. हा Project काय शिकवतो?
Optimal पद्धत असा Page बाहेर काढते ज्याचा पुढील वापर भविष्यात सर्वात उशिरा होईल किंवा पुन्हा होणारच नाही.

## 2. सोपे शब्द
ही पद्धत पुढील Page क्रम आधीच माहिती असल्यास योग्य निर्णय घेते. म्हणून ती तुलना करण्यासाठी आदर्श उदाहरण आहे.

## 3. वापरण्याची पद्धत
Reference String आणि Frame संख्या भरा. कोणता Page पुढे लवकर लागणार नाही हे पाहून replacement कसा निवडला ते समजा.

## 4. उदाहरण
Frames मध्ये 1,2,3 असून पुढील क्रम 2,1,4 असेल, तर 3 पुढे येत नसल्यास 3 बाहेर काढणे योग्य ठरू शकते.

## 5. लक्षात ठेवण्यासारखे
वेगवेगळ्या पद्धतींच्या Page Fault Count ची तुलना करा.

## 6. मर्यादा
खऱ्या वेळी Operating System ला भविष्य माहीत नसते; म्हणून Optimal साधारणतः benchmark म्हणून वापरतात.

## 7. स्वतः तपासा
- Frames ची संख्या बदलल्यावर काय होते?
- कोणता Page बाहेर काढला गेला आणि का?
- दोन Algorithms चा निकाल वेगळा का असू शकतो?

## 8. लक्षात ठेवा
हा प्रात्यक्षिकासाठीचा Simulator आहे. स्क्रीनवरील परिणाम समजून घेणे हा उद्देश आहे.

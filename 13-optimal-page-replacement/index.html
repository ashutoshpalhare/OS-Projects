How Optimal Works

  1. Read the next page reference.
  2. If the page is already in a frame, it is a HIT.
  3. If an empty frame exists, place the page there.
  4. Otherwise look ahead in the reference string.
  5. Replace the page used farthest in the future, or never used again.

Exam Points

  • Also called OPT or MIN algorithm.
  • Produces the minimum possible page faults for a fixed reference string and frame count.
  • It requires knowledge of future references, so it is mainly theoretical.
  • Useful as a benchmark for other page replacement algorithms.

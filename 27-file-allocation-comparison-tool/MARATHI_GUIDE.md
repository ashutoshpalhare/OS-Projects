# File Allocation Comparison — सोप्या मराठीत मार्गदर्शक

> कठीण शब्द कमी ठेवून, रोजच्या उदाहरणांनी संकल्पना समजावण्याचा प्रयत्न.

## 1. हा Project काय करतो?
हा Project फाइल ठेवण्याच्या वेगवेगळ्या पद्धती तुलना करतो. जागेचा वापर, फाइलमध्ये प्रवेश आणि blocks शोधणे यावर पद्धतींचा परिणाम होतो.

## 2. महत्त्वाचे शब्द
Contiguous पद्धत सलग जागा मागते; Linked पद्धत blocks जोडते; Indexed पद्धत index मधून blocks शोधते.

## 3. वापरण्याची पद्धत
एकाच file size आणि disk स्थितीवर वेगवेगळ्या allocation पद्धती पाहा. कोणती पद्धत कशी जागा वापरते ते तुलना करा.

## 4. छोटं उदाहरण
Blocks 5,6,7 सलग असतील तर Contiguous सहज बसते; जागा विखुरलेली असेल तर Linked पद्धत उपयोगी पडू शकते.

## 5. मुख्य नियम
तुलना करताना space usage, access आणि fragmentation हे मुद्दे पाहा.

## 6. मर्यादा
एकच पद्धत सर्व फाइल्स आणि सर्व disk परिस्थितीसाठी सर्वोत्तम नसते.

## 7. स्वतः करून पाहा
- Example चालवून पहा.
- एक input बदला आणि परिणामात काय बदलले ते लिहा.
- हा विषय Operating System मध्ये का महत्त्वाचा आहे ते एका वाक्यात सांगा.

## 8. लक्षात ठेवा
हा विद्यार्थ्यांसाठी तयार केलेला शैक्षणिक Simulator आहे. प्रत्यक्ष Operating System मध्ये अधिक नियम आणि परिस्थिती असू शकतात.

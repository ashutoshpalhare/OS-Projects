# Page Replacement Algorithm Comparison — सोप्या मराठीत मार्गदर्शक

> 15 वर्षांच्या विद्यार्थ्यालाही समजेल अशा भाषेत.

## 1. हा Project काय शिकवतो?
हा Project FIFO, LRU आणि Optimal सारख्या पद्धती एकाच Page क्रमावर तपासतो. कोणत्या पद्धतीत कमी Page Fault होतात हे समजते.

## 2. सोपे शब्द
समान Reference String आणि समान Frames ठेवल्यासच तुलना योग्य होते. Page Fault कमी असणे अनेकदा चांगले, पण algorithm ची अंमलबजावणीही महत्त्वाची असते.

## 3. वापरण्याची पद्धत
एकाच input वर उपलब्ध Algorithms चालवा. प्रत्येकाची Fault संख्या आणि बदललेले Frames तुलना करा.

## 4. उदाहरण
जर FIFO ला 8 Faults आणि LRU ला 6 Faults मिळाले, तर त्या input साठी LRU ने कमी Faults दिले.

## 5. लक्षात ठेवण्यासारखे
Fault Rate = Page Faults ÷ एकूण Page references; उपलब्ध असल्यास percentage पाहा.

## 6. मर्यादा
एका उदाहरणात चांगला निकाल आला म्हणून तो प्रत्येक input वर सर्वोत्तम असेलच असे नाही.

## 7. स्वतः तपासा
- Frames ची संख्या बदलल्यावर काय होते?
- कोणता Page बाहेर काढला गेला आणि का?
- दोन Algorithms चा निकाल वेगळा का असू शकतो?

## 8. लक्षात ठेवा
हा प्रात्यक्षिकासाठीचा Simulator आहे. स्क्रीनवरील परिणाम समजून घेणे हा उद्देश आहे.

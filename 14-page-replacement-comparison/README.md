# Project 14 – Page Replacement Algorithm Comparison

A web-based Operating Systems learning tool that compares FIFO, LRU and Optimal page replacement algorithms using the same reference string and frame count.

## Features
- FIFO, LRU and Optimal algorithms
- Same input for all algorithms
- Configurable number of frames
- Page faults and page hits
- Fault rate and hit rate
- Best algorithm highlighting
- Frame-by-frame comparison
- Load Example and Reset
- Responsive UI
- Dark mode
- HTML, CSS and JavaScript only

## Example
Reference String: 7,0,1,2,0,3,0,4,2,3,0,3,2  
Frames: 3

## Algorithms
- FIFO: replaces the page that entered memory first.
- LRU: replaces the least recently used page.
- Optimal: replaces the page whose next use is farthest in the future.

The project helps students compare practical and theoretical page replacement strategies and understand why Optimal is used as a benchmark.

## How to Run
Open index.html in a modern browser. No installation or backend is required.

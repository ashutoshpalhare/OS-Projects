Algorithms Compared

  • FIFO: Replaces the page that entered memory first.
  • LRU: Replaces the page that has not been used for the longest time.
  • Optimal: Replaces the page whose next use is farthest in the future.

Key Observation

Optimal provides the theoretical minimum number of page faults. FIFO and LRU can be compared against it to understand how closely practical strategies perform.
